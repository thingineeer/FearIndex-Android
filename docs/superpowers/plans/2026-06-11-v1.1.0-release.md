# FearIndex Android 1.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring Android to iOS v1.8.0 parity for KOSPI Fear Index, updated home/chart/vote/settings flows, compliant ads, locale handling, Play metadata, screenshots, and production release prep.

**Architecture:** Keep the existing Clean Architecture boundaries. Add KOSPI as a first-class domain type, wire data and presentation through repository/usecase interfaces, and keep Firebase/AdMob behavior Android-only without modifying the shared iOS project.

**Tech Stack:** Kotlin 2.x, Jetpack Compose, Hilt, Coroutines/Flow, Retrofit/kotlinx.serialization, Firebase Auth/Firestore/Functions/FCM/Remote Config, Google Mobile Ads + UMP, Fastlane Supply.
